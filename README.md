🌦️ SkyPulse

A modern and interactive Weather Analytics Dashboard built using **Power BI**.  
This dashboard provides real-time style weather insights with a clean dark-themed UI and data visualizations.

---
🚀 Features
🌡️ Current Temperature Overview
📈 Weekly Forecast Analysis
🌅 Sunrise & Sunset Tracking
💨 Wind Speed Monitoring
💧 Humidity Analysis
👁️ Visibility Metrics
🌍 Air Quality Index (AQI)
☔ Chance of Rain Visualization
🌧️ Precipitation Tracking
⚙️ Atmospheric Pressure Monitoring
☀️ UV Index Analysis
🔥 Modern Glassmorphism UI Design
🛠️ Tools & Technologies

- Power BI
- Data Visualization
- DAX
- Custom UI Design
- Interactive Charts
